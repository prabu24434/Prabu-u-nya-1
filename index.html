Status Database (GitHub Gist)

Data pesanan & keranjang disimpan online di GitHub Gist lewat serverless function /api/gist di Vercel — token GitHub tidak pernah disimpan atau diketik di browser sama sekali.

Kalau status di pojok kanan atas menunjukkan "Gagal tersambung", cek dulu di dashboard Vercel:

  1. Buka proyek ini di vercel.com/dashboard
  2. Masuk ke Settings → Environment Variables
  3. Pastikan ada GITHUB_TOKEN (scope gist saja) dan GIST_ID
  4. Setelah menambah/mengubah env var, klik Redeploy supaya function membaca nilai terbaru
